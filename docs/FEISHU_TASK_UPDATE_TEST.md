# 飞书已有任务更新：隔离验证

用户已完成浏览器授权，并报告 task_read=passed、identity_match=passed、task_write=not_tested。测试证明用户身份能读到原生自动化创建的任务，不能据此宣称更新或长期自动同步已实现。

程序 tools/update_feishu_test_task.py 仅连接现有本机独立测试配置，按虚构姓名唯一选择已关联记录，读取其原飞书任务。只解析明确未来日期和非空行动，不把模糊日期擅自转换。

需要测试应用发布 User token scopes `task:task:read` 和 `task:task:writeonly`。新授权请求两项，旧读取授权不能自动升级成写权限。应用密钥隐藏输入、用户令牌只在内存中，不保存、不输出。

本机预览原/新标题及候选全天日期，用户输入 YES 后再核对双方是否变化。使用 PATCH /task/v2/tasks/:task_guid，update_fields 仅 summary、due；不新建、不删除、不完成任务，不写客户表，不改负责人/关注人/描述。读回验证原任务ID及新字段，失败或结果未知时停止，不盲目重试。

8个模拟更新测试及9个OAuth测试通过，覆盖唯一身份、字段限制、并发变化、已完成任务保护、模糊时间暂停、全天日期与最少授权。官方任务鉴权/更新文档已核实；仍需用户Mac上的真实隔离写入测试。

这是一笔明确确认的更新探针，不是后台自动同步服务。原生更新自动化仍未启用、HTTP动作中未填密钥。通过验证后再实现有持久化基线与冲突处理的云端执行器；不能以本机测试命令替代Mac关机情况下的自动运行。
