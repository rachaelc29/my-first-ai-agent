# 完成回写格式调整

用户确认：最新follow包含实际完成时间与最终文字；任务完成后下次follow清空。

实现：Apple 桥接读取 completionDate，Python 按 Australia/Melbourne 转换，生成 `YYYY-MM-DD HH:MM:SS +HHMM（墨尔本时间）`，换行后附原样行动内容。夏令时使用 +1100，冬季使用 +1000。不使用程序启动/同步时间，不让 AI 改写文字。

同一次飞书记录更新请求写入任务状态、最新follow、空的下次follow，然后读回验证。原有冲突及字段白名单保护保持有效。缺少完成时间、没有时区或两边变化时暂停，不清空计划。

已同步的旧测试任务可做一次受保护格式升级：只有当前飞书计划、最新follow仍与旧基线一致，且最新follow正好等于旧任务最终内容、任务日期内容未变，才添加真实完成时间并清空旧计划。若已填写新计划，不清空它。编号和已完成任务保留，不重新创建。

71 个模拟测试通过，包含时间缺失保护、冬夏时区、旧任务一次升级、新计划不清空、重跑去重、人工确认路径及原同步逻辑。Swift新字段仍须在 Mac 编译与实机验收。正式客户表未访问或写入。

Mac 更新需替换 mac/RemindersBridge.swift、crm_sync/model.py、crm_sync/engine.py，然后本地重新编译。不要删除配置或数据库；用户在下一次测试同步之前保持测试记录不变。
