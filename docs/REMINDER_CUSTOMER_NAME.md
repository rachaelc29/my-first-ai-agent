# Apple 提醒标题显示客户姓名

测试程序读取指定虚构记录的「名字」，生成标题 `【名字】行动内容`。身份仍通过记录 ID/任务编号关联，不能因为姓名相同而绑定到另一客户。

显示名字作为单独的 Task 字段和提醒备注中的编码元数据保存。回读时去掉已知姓名前缀，备注标记也排除；飞书下次follow和最新follow只写行动内容以及规定的日期/实际完成时间，不混入显示前缀。不是通过正则猜测所有方括号文本。

已有未完成任务可原位增加名字，不换任务编号、不创建副本；已完成历史任务不自动改标题，避免改写其完成后修改时间。后续新建任务包含姓名。虚构姓名若在飞书改变，未完成任务的显示标签可更新，不修改其它CRM字段。

用户在 Apple 改行动内容时应保留 `【名字】` 标签，备注中的 CRM_SYNC_NAME/CRM_SYNC_TASK 标记由程序管理。如果标签被改掉或元数据损坏，程序暂停，不把它当成更换客户或把标签写回CRM。

79 个模拟测试通过，包括名字附加、旧任务原位更新、改名不改其它字段、计划回写不带标签、完成内容不带标签。Swift显示与回读仍待Mac真机验收，不宣称云端运行过Apple接口。

用户需先停止 watch，再更新四个文件：mac/RemindersBridge.swift、crm_sync/model.py、crm_sync/engine.py、crm_sync/feishu.py；重编译后先单次同步核对，之后恢复轮询。

名字可能在手机锁屏通知中显示，这是用户要求的客户识别方式；不额外加入电话、预算或沟通历史。正式客户表仍不写入；本次云端未调用任何客户记录接口。
